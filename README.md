## 이런 노트예요

📓 **진짜 노트처럼**
입체 표지를 열면 속지가 펼쳐지고, 책장을 넘기면 종이가 넘어가요. 남은 페이지만큼 두꺼워지는 종이 단면, 쪽번호, 인덱스 스티커까지.

✏️ **점 위에 쓰고 그리기**
빈 칸을 눌러 바로 쓰고, 점에서 끌면 볼펜·연필로 그은 듯한 선이 그어져요. 칸 가운데서 끌면 제목용 큰 글자 칸이 생겨요.

• **불렛저널 문법 그대로**
할 일 •, 일정 ○, 메모 – 기호를 넣고, 눌러서 완료 ✕ · 미룸 › · 취소선으로 바꿔요. 날씨·기분·일상 아이콘도 함께.

🖍 **형광펜과 손글씨 글씨체**
마커로 그은 듯한 형광펜, 콕 찍은 점. 손글씨부터 데코 글씨체까지 골라 쓰는 다양한 글씨체.

🗂 **찾고, 모아 보고, 다시 쓰기**
모든 페이지 모아보기와 순서 바꾸기, 노트 안 글자 찾기, 자주 쓰는 페이지는 템플릿으로 저장.

📱 **어디서나**
PC에서는 양쪽 펼침면, 휴대폰에서는 한 장씩 넘기며 두 손가락으로 확대해서 써요. 애플펜슬 호버도 지원해요.

---

## 시작하기

1. 노트 이름, 크기(A6 · B6+ · A5 · B5), 표지 색을 골라 노트를 만들어요.
2. 처음 펼치면 짧은 안내가 하나씩 짚어 줘요.
3. 막히면 `?` (휴대폰은 위쪽 ⋯ → 도움말)로 단축키와 안내를 다시 볼 수 있어요.

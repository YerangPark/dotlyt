# Dotlyt

종이 불렛저널을 옮긴 도트지 웹 다이어리. 요구사항 문서: https://claude.ai/artifact/XNsZEiRCJYc5H4bKinU4ds

## 로컬에서 띄우기

Node 20 이상이 필요하다.

```bash
cd ~/Documents/dev/dotlyt
npm install
npm run dev
```

브라우저에서 http://localhost:5180 을 연다.

휴대폰으로 써보려면 PC와 같은 와이파이에 연결한 뒤 `npm run dev:phone`으로 띄우고, 터미널에 찍히는 `Network: http://192.168.x.x:5180` 주소를 휴대폰 브라우저에서 연다.

데이터는 브라우저(localStorage)에만 저장된다. 처음부터 다시 하려면 개발자 도구 콘솔에서 `localStorage.removeItem('dotlyt:v1')` 후 새로고침.

## 단계 1 사용법

PC 넓은 화면(가로 약 840px 이상)은 양쪽 펼침면, 좁은 화면과 모바일은 한 장씩 보인다.

| 하고 싶은 것 | PC | 모바일 |
| --- | --- | --- |
| 표지(메인 화면) | 앱을 열면 표지. 표지나 '노트 펼치기'를 누르면 표지가 넘어가고 속지가 차르륵 넘어가며 마지막 페이지가 열림. 노트 안에서 왼쪽 위 노트 이름을 누르면 노트가 닫히며 표지로 | 같음 |
| 글자 쓰기 | 빈 칸 클릭 후 타이핑, Enter로 다음 줄 | 빈 칸 탭 후 입력 |
| 큰 글자 (네모칸) | 칸 가운데에서 끌어 네모칸을 만들고 타이핑. Shift+Enter로 줄바꿈 (줄 수만큼 칸이 있으면 줄마다 칸 줄에 딱 맞춰 씀: 높이 2칸에 두 줄이면 한 칸에 한 줄, 칸이 모자라면 글자가 작아짐), Enter로 마치기. 1×1보다 큰 네모칸은 쓰는 중이거나 혼자 골랐을 때 네 모서리 손잡이로 크기 바꾸기 | 같음 |
| 글자 고치기 | 글자나 네모칸 클릭, 또는 하나를 고른 상태에서 Enter | 탭 |
| 굵게 | ⌘B / Ctrl+B 또는 도구 모음 B (쓰고 있는 글자, 고른 글자, 아니면 앞으로 쓸 글자) | Aa 버튼 |
| 글씨체 | 도구 모음 Aa → 나눔펜, Caveat, 교보 손글씨 2025, 진주의일기장, 온글잎 영롱, 묘은또박, 그리운 고운, 푸어스토리(손글씨) / 프리텐다드(기본), 깍두기 도면체, 고운돋움, IBM Plex, Noto Sans(고딕) / 고운바탕, Noto Serif(명조) / 데코박스·데코라인·데코섀도(영문·숫자 전용), Bebas(제목용) / Intel One Mono(고정폭). 글씨체가 많아 손글씨 / 고딕·명조 / 제목·고정폭 탭으로 나눠 보여주고, 지금 글씨체가 있는 탭이 먼저 열림. 직접 넣은 글씨체 파일과 라이선스는 `public/fonts` | 같음 |
| 글자 크기·정렬 | 도구 모음 Aa → 크기(보통·작게·아주 작게), 가로 정렬(왼쪽·가운데·오른쪽: 줄 글자는 차지한 칸 안에서, 네모칸은 네모칸 안에서 / 양쪽: 네모칸 줄마다 띄어쓰기를 벌려 폭에 맞춤, 예: M T W T F S S), 세로 정렬(위·가운데·아래) | 같음 |
| 기호 넣기 | 커서가 있는 빈 칸을 한 번 더 클릭, 또는 도구 모음 기호 버튼 → • ○ – 중 고르기 (키: * O -). 기호 색은 고른 펜 색 | 한 번 더 탭, 또는 기호 버튼 |
| 아이콘 넣기 | 빈 칸을 한 번 더 눌러 뜨는 기호 팝업 → 아이콘 → 단색 아이콘(날씨·기분·일상·활동·일·집·기타 44개), 1~3칸 크기, 색은 펜 색 | 같음 |
| 색 바꾸기 | 그려 둔 글자·네모칸·아이콘·기호·선을 고르면 위 막대에 컬러점 → 펜 색 5가지 중 고르기, 형광펜을 고르면 형광펜 색 컬러점 (고르기 도구로 형광펜을 눌러 고름) (펜 색은 그대로, ⌘Z로 되돌리기) | 같음 |
| 복사·붙여넣기 | ⌘C / ⌘X / ⌘V, 또는 오른쪽 클릭 메뉴(항목 위: 복사·잘라내기·붙여넣기·복제·지우기, 빈 칸: 그 칸에 붙여넣기). 빈 칸을 고르고 붙이면 그 칸에, 아니면 한 칸 옆에. 선택 막대에 복사 버튼 | 선택 막대 복사 → 빈 칸 한 번 더 눌러 붙여넣기 |
| 기호 빠른 입력 | 줄 맨 앞에서 `* ` 할 일, `o ` 일정, `- ` 메모. 기호 팝업 키(X, >, <, C, O, T, -)와 함께 한글 자판이어도 한영 전환 없이 됨 | 같음 |
| 기호 상태 바꾸기 | 기호 클릭 → 팝업 (X 완료, > 미룸, < 일정으로, 색, C 취소선, Del 지우기) | 기호 탭 |
| 인덱스 스티커 | 위쪽 깃발 버튼으로 붙이기 (색: 마커 오렌지·번트 시에나·스카이·버블검·새싹·듀드롭·코코아·차콜). 노트 오른쪽 탭을 누르면 이동, 우클릭으로 수정·떼기. 스티커는 페이지 순서대로 붙고, 페이지를 옮기면 따라 바뀜 | 탭 끝을 누르면 인덱스 목록, 길게 누르면 수정 |
| 선 긋기 | 점 위에서 끌기 (가로·세로만). 펼침면에서는 반대쪽 페이지까지 이어 그을 수 있음(가운데 접히는 부분은 비움, 되돌리기 한 번에 함께) | 점 위에서 한 손가락으로 끌기 |
| 펜 바꾸기 | 도구 모음의 볼펜 / 연필 | 펜 버튼을 누를 때마다 바뀜 |
| 선 모양 | 도구 모음의 점선 · 두 줄 (같이 켜면 두 줄 점선) | 선 모양 버튼을 누를 때마다 실선 → 점선 → 두 줄 → 두 줄 점선 |
| 분할 그리드 | 도구 모음의 분할 버튼(PC): 종이 위 여백에 ⅓ ½ ⅔ 지점을 가장 가까운 점에 맞춰 짧은 회색 선으로 표시 | 같음 |
| 여러 개 고르기 | Shift + 끌기, 또는 고르기 도구 (사각형에 걸치기만 해도 골라짐, 펼침면 양쪽에 걸쳐 고르기 가능, Shift+클릭으로 하나씩 넣고 빼기) → 위에 뜨는 막대로 지우기·복제·굵게 | 고르기 도구를 켜고 끌기 |
| 형광펜 | 도구 모음 펜 묶음(볼펜·연필 옆)의 형광펜을 켜고 끌기: 시작한 칸에서 가로나 세로 한 줄로 곧게 칠함. 칸을 꽉 채우지 않고 마커로 그은 띠처럼(글자 아래쪽에 낮게, 끝은 거칠게). 칸 하나만 칠하면 마커로 콕 찍은 동그란 점. 한 번 그은 것은 한 획이라 위아래 줄·옆의 점과 합쳐지지 않음(같은 자리를 다시 그으면 덮어씀) (펼침면 양쪽에 걸쳐 가능). 색 7가지(회색 포함), 지우기 선택 시 칠한 칸 지우기. 글자는 칠한 칸 위에 그대로 씀 | 같음 |
| 지우개 | 지우개 도구를 켜고 문지르기 (닿은 것을 지움, Esc로 끄기) | 같음 |
| 모든 페이지 모아보기 | 위쪽 격자 버튼 → 미리보기를 끌어서 순서 바꾸기, 누르면 그 페이지로, 체크해서 여러 장 지우기 | 같음 |
| 페이지 지우기 | 위쪽 휴지통 버튼 (펼침면 단위, 확인 후 지움, 되돌릴 수 없음) | 위쪽 휴지통 (한 장 단위) |
| 옮기기 | 고른 것을 끌기 (펼침면 반대쪽 페이지로 넘길 수 있고, 페이지 밖으로 끌면 가장자리 안쪽으로 맞춰짐) | 고른 것을 끌기 |
| 지우기 | Delete / Backspace | 휴지통 버튼 |
| 되돌리기 | ⌘Z / Ctrl+Z, 다시 실행 ⇧⌘Z / Ctrl+Y. 펼침면 양쪽 페이지를 오가며 그려도 그린 순서대로 되돌림 | 도구 모음 버튼 |
| 종이 단면 | 펼친 노트 양옆 종이 단면 두께가 그쪽에 남은 페이지 수만큼 (앞쪽이면 오른쪽이 두껍고 뒤로 갈수록 왼쪽이). 넘기면 부드럽게 바뀜 | 같음 (오른쪽만) |
| 쪽번호 | 종이 아래 가운데에 노트 안 순서대로 (순서를 바꾸면 따라 바뀜) | 같음 |
| 페이지 넘기기 | 위쪽 ‹ › 또는 ← → 키 (펼침면 단위). 책장이 책등을 축으로 넘어가고, 페이지 크기가 다르면 노트 크기도 부드럽게 바뀜 | 위쪽 ‹ › (한 장이 넘어가며 사라짐) |
| 글자 찾기 | ⌘F / Ctrl+F 또는 위쪽 돋보기 → 모든 페이지의 글자·네모칸·인덱스 이름에서 찾기. Enter·↓로 다음, ⇧Enter·↑로 이전, 고르면 그 페이지로 가서 그 글자를 골라 보여줌 | 위쪽 돋보기 |
| 템플릿 | 위쪽 템플릿 버튼(L) → 지금 페이지나 펼침면을 이름 붙여 저장, 저장한 것을 '새 페이지로' 추가하거나 '현재 페이지에 삽입'(⌘Z로 되돌리기). 이 브라우저에만 저장(`dotlyt:templates`) | 같음 |
| 단축키 | ? 키로 목록. 글자를 쓰고 있지 않을 때: P 펜, W 굵기, D 점선, ⇧D 두 줄, C 색, H 형광펜, E 지우개, V 고르기, G 분할 그리드, T 글자 스타일, N 새 페이지, O 모아보기, L 템플릿. ⌘D 복제. 한글 자판이어도 됨. 도구에 마우스를 올리면 이름·설명·단축키 툴팁 | — |

끌기를 점 가까이에서 시작하면 선, 칸 가운데에서 시작하면 네모칸이 된다. 커서가 위치에 따라 바뀐다: 점 근처는 펜(선 긋기), 칸 가운데는 네모 커서(네모칸), 그려둔 항목 위는 손가락(고르기·고치기), 고른 것 위는 잡는 손(옮기기).
선을 고른 상태에서 펜, 굵기, 점선, 색을 누르면 고른 선에 바로 적용된다.

## 디자인

앱 화면은 미니멀 모노 스타일: 흰 바탕, 진한 외곽선 대신 아주 옅은 1px 선(#ece8e3)과 회색 채움으로 구분, 주 버튼은 검정으로 채움, 선택·포커스는 파랑(#2383e2) 하나, 모서리 6~10px. 글씨는 프리텐다드. 노트(표지·종이·스티커)는 '제품'이라 그대로 둔다. 색·모서리 토큰은 `src/styles.css` 위쪽 `:root` 한 곳. 같은 선택자는 한 규칙으로 합쳐 두었고, 미디어 쿼리나 같은 요소의 다른 클래스보다 뒤에 와야 이기는 값만 '뒤에 와야 이기는 값들' 구역에 따로 남아 있다.

## 구조

- `src/store.ts` — Zustand 상태(노트, 페이지, 커서, 선택, 페이지별 되돌리기 기록)와 localStorage 저장
- `src/geometry.ts` — 격자 좌표, 글자 폭 재기, 클릭 판정, 점 스냅
- `src/ink.ts` — 볼펜·연필로 그은 것 같은 선 모양 (요소 id로 흔들림을 고정)
- `src/components/PageView.tsx` — 도트지 SVG와 입력 처리(포인터, 글자 입력창)
- `src/components/page/` — PageView에서 나눈 조각: 선·기호·아이콘·네모칸 글자 그리기(`glyphs`), 기호 팝업, 고른 것 막대, 아이콘 고르기, 분할 그리드·고르기 사각형(`overlays`), 커서 모양, 계산 도우미
- `src/shortcuts.ts` — 단축키 목록 (키 처리·툴팁·단축키 창이 같이 씀)
- `src/components/Tooltip.tsx`, `FindBar.tsx`, `TemplatesPanel.tsx`, `ShortcutHelp.tsx`
- `src/components/Toolbar.tsx`, `NotebookForm.tsx`

모든 좌표는 픽셀이 아니라 격자 칸 단위로 저장한다. 글자는 칸 `(x, y)`에서 시작하고, 선은 점과 점을 잇는다(점은 가장자리 한 줄을 뺀 정수 좌표).
